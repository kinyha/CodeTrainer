# kotlinlang.l2.SealedResult — L2

## Идея

`sealed interface` закрывает множество вариантов в пределах известной иерархии,
поэтому `when` проверяется компилятором на исчерпывающий разбор. `Outcome` объявлен
ковариантным (`out T`): ошибка имеет тип `Outcome<Nothing>` и подходит вместо
`Outcome<R>` без небезопасного приведения.

## Что легко сделать неправильно

- добавить ветку `else` и потерять проверку компилятора при новом варианте результата;
- повторно вызвать `transform` для ошибки;
- завернуть исходную ошибку в новую и потерять объект `cause`.
