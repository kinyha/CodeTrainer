# DiscountPolicyChain — L3

## Идея

Порядок policy задаёт бизнес-приоритет: применяется первая подходящая скидка.
Денежный результат округляется один раз на границе расчёта.

## Что легко сделать неправильно

- сложить взаимоисключающие скидки;
- использовать `double` для денег;
- не проверить отрицательную скидку или скидку больше subtotal.
