# TransferInvariantReview — L4

## Идея

Сначала проверяются все инварианты, затем создаётся новый snapshot. Поэтому
ошибка не оставляет частично изменённого состояния, а сумма денег сохраняется.

## Что легко сделать неправильно

- списать до проверки target account;
- сравнивать `BigDecimal` через `equals` при разном scale;
- вернуть наружу изменяемую копию.
