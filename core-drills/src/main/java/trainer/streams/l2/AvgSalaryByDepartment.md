# streams.l2.AvgSalaryByDepartment — L2

## Идея

Двухаргументный `groupingBy` обычно создаёт `HashMap`, поэтому сортировка входного
стрима не гарантирует порядок ключей результата. Трёхаргументная форма принимает
`mapFactory`: `TreeMap::new` сохраняет ключи отсортированными без второго прохода.

## Что легко сделать неправильно

- вызвать `.sorted()` до `collect` и вернуть `HashMap`;
- сначала собрать `HashMap`, а потом вручную сортировать записи;
- использовать `toMap` без merge-функции и упасть на повторяющемся отделе.

## Подсказки

1. Нужен downstream-коллектор для среднего значения.
2. У `groupingBy` есть форма с фабрикой результирующей Map.
3. Сигнатура: `groupingBy(classifier, mapFactory, downstream)`.
