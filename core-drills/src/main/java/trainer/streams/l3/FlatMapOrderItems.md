# FlatMapOrderItems — L3

## Идея

`flatMap` превращает поток заказов в поток позиций, downstream collector
суммирует quantity, а финальная проекция возвращает стабильный порядок.

## Что легко сделать неправильно

- вернуть одну строку на позицию вместо агрегации товара;
- потерять quantity при одинаковом product id;
- полагаться на случайный порядок `HashMap`.
