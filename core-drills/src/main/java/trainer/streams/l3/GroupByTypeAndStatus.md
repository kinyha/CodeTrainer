# GroupByTypeAndStatus — L3

## Идея

Два вложенных `groupingBy` строят индекс type → status → count. `EnumMap`
компактен и явно ограничивает ключи доменными enum.

## Что легко сделать неправильно

- сгруппировать только по одному измерению;
- использовать изменяемый внешний accumulator после возврата;
- ожидать отсутствующие комбинации со значением zero.
