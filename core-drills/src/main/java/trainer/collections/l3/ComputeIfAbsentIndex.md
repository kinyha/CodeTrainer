# ComputeIfAbsentIndex — L3

## Идея

`computeIfAbsent` создаёт bucket только при первом ключе. После построения нужно
заморозить не только внешнюю `Map`, но и каждый вложенный `List`.

## Что легко сделать неправильно

- вернуть изменяемые списки через формально неизменяемую map;
- потерять порядок сотрудников внутри отдела;
- молча принять `null` и получить ошибку далеко от причины.
