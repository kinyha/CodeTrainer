# TokenBucketRateLimiter — L5

## Идея

Bucket допускает burst до `capacity`, затем пополняется с постоянной скоростью.
Монотонные часы внедрены явно, поэтому тест не зависит от wall clock и sleep.

## Что легко сделать неправильно

- использовать `currentTimeMillis` и получить скачок при коррекции времени;
- не ограничить накопление capacity;
- разнести refill и списание по разным критическим секциям.
