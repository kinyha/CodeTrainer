# BoundedBufferWaitNotify — L3

## Идея

Producer ждёт свободное место, consumer — элемент. Условие всегда проверяется в
`while`: поток может проснуться без нужного состояния или после другого потока.

## Что легко сделать неправильно

- заменить `while` на `if` и сломаться на spurious wakeup;
- вызвать `wait` вне монитора;
- использовать `notify`, когда ждут разные условия.
