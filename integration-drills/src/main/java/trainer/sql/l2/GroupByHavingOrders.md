# sql.l2.GroupByHavingOrders — L2

## Идея

`WHERE` отбирает отдельные строки до группировки, а `HAVING` фильтрует уже
сформированные группы. Поэтому статус заказа проверяется в `WHERE`, а условие на
`COUNT(*)` — в `HAVING`.

## Что легко сделать неправильно

- поместить `COUNT(*) >= ?` в `WHERE`, где агрегат ещё не вычислен;
- посчитать отменённые и новые заказы вместе с доставленными;
- забыть второй ключ сортировки и получить недетерминированный порядок при равенстве.
