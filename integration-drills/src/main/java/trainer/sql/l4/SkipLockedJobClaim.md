# SkipLockedJobClaim — L4

## Идея

`FOR UPDATE SKIP LOCKED` превращает таблицу в конкурентную очередь: worker
захватывает старейшую доступную строку и не ждёт lock другого worker.

## Что легко сделать неправильно

- выполнить select вне явной транзакции и сразу потерять lock;
- забыть стабильный порядок claim;
- принять `SKIP LOCKED` за гарантию справедливости.
