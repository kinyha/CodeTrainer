# MonthlyDeliveredRevenue — L3

## Идея

PostgreSQL `DATE_TRUNC` задаёт календарный bucket, `SUM` считает только
доставленную выручку. `::date` делает тип результата удобным для JDBC.

## Что легко сделать неправильно

- включить cancelled/new заказы;
- группировать по полному timestamp;
- забыть детерминированный `ORDER BY`.
