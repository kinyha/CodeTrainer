# RankCustomersBySpend — L3

## Идея

CTE сначала агрегирует spend, затем window function ранжирует уже агрегированные
строки. `DENSE_RANK` не оставляет разрывов после одинаковых значений.

## Что легко сделать неправильно

- применить window до `GROUP BY`;
- перепутать `ROW_NUMBER`, `RANK` и `DENSE_RANK`;
- ранжировать cancelled заказы.
