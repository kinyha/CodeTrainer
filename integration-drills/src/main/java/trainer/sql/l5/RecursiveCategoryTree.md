# RecursiveCategoryTree — L5

## Идея

Anchor выбирает корень, recursive member присоединяет детей. Depth и path
накапливаются на каждом шаге, а `name::text` согласует типы ветвей `UNION ALL`.

## Что легко сделать неправильно

- развернуть join parent/child в обратную сторону;
- получить несовместимые VARCHAR/TEXT типы;
- зациклиться на повреждённой иерархии.
